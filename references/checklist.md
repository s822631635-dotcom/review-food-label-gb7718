# 全文检查清单
使用时逐行记录状态、证据、条款及适用例外。以下为导航，精确结论以全文为准。

| 条款 | 检查内容及条件 |
| --- | --- |
| 1、2 | 适用范围及全部术语；以计量销售也可能属于预包装食品；区分规格、生产日期、保质期和数字标签 |
| 3.1—3.6 | 法规与标准；清晰醒目持久不分离；科学和公序良俗；真实不误导；无疾病防治暗示及普通食品保健功能暗示；规范汉字 |
| 4.1 | 一般强制项目逐项检查；以计量销售和其他豁免须单列依据 |
| 4.2.1—4.2.2 | 真实属性名称及法定/标准命名；易混淆新创或商标名称的同版临近位置、字高、字体和颜色要求 |
| 4.3.1—4.3.2 | 单一配料也标配料表及引导词；加入质量递减；不超过2%的排序例外；已挥发或去除的配料 |
| 4.3.3 | 复合配料展开；有国家/行业/地方标准且加入量小于25%的例外；复合配料中复合配料的例外 |
| 4.3.4—4.3.4.3、B | 添加剂及强化剂通用名称和最终功能；复配展开；带入及其他可不标情形；选择一种附录B形式；≤60cm²用功能类别+INS的条件及例外；添加剂项按总质量排序，直接和非直接使用分开处理 |
| 4.3.5—4.3.6 | 可食包装配料；直接添加菌种、发酵归类、灭活或去除及标示时的工艺提示 |
| 4.4.1、A.5 | 强调添加或含有、名称提及与定量；先核对A.5.4全部例外；区分添加量和成品含量；香精调味图案限制及邻近提示 |
| 4.4.2、A.5.3 | 强调低或无时标含量；无/不含原则为0并核对其他标准例外；禁止对添加剂、污染物及不允许存在物质作无/不含声称；不添加/不使用及同义语限制，核对法定例外 |
| 4.5 | 净含量与食品名称同一展示版面；数值、单位和字高等另查适用计量及监管规则 |
| 4.6 | 主体名称地址联系方式按法规及监管要求核实，不能从本标准虚构详细规则 |
| 4.7、A.2 | 年月日顺序；生产日期和到期日；具体喷码部位；不得加贴补印修改；≥6个月及≤20cm²例外；消费保存期为自愿项目 |
| 4.8、A.3 | 贮存条件及开封后要求与产品依据核对 |
| 4.9—4.11 | 生产许可及执行标准；质量等级仅在执行标准规定等级时标示 |
| 4.12、D | 麸质谷物、甲壳纲、鱼、蛋、花生、大豆、乳含乳糖、坚果；配料内易辨识提示或临近提示；交叉接触提示为鼓励；逐项核实D.4深加工及D.5例外，不笼统豁免所有衍生物 |
| 4.13—4.14 | 营养标签另查GB28050/GB13432；警示语另查法律、产品标准及公告 |
| 4.15 | 食品辐照在名称临近位置提示；辐照配料在配料表括号或临近位置提示；核对专门规定 |
| 5 | 非直接消费者标签的必要项目；其他事项用数字标签、说明书或合同提供 |
| 6 | 特殊食品专门规定优先 |
| 7 | 声称真实准确，有依据；不得只凭文案确认功效 |
| 8.1—8.2 | 全部可见中外文均检查；中文标签及对应关系和例外；外文配料须中文对应，中国另要求的项目也须补列 |
| 8.3—8.4 | 进口商/代理商信息、境外注册编号、原产国；分装或灌装国不同须同时标示 |
| 8.5—8.7 | 进口日期推算条件及≥6个月例外；人群、食用量、方法中文对应；可不标SC和产品标准 |
| 9.1—9.7 | 数字与实体一致、身份明示、扫码一级页面直接展示无阅读干扰、清晰不篡改；简化实体项目须另有规则依据，不能任意移走强制信息 |
| 10.1—10.2 | 指定酒类、食醋、盐、固态糖、味精的保质期豁免须生产日期条件；指定酒类生产日期豁免须批号条件；分别判断，不自动叠加 |
| 10.3 | ≤20cm²保留项目完整核对；其他项目在销售容器、随附说明或数字标签提供，不是全部消失 |
| A.1—A.6 | 日期、贮存、归类配料、定量及豁免、同义语；批号和食用方法为推荐内容，专门规定除外 |
| B.1—B.5 | 各添加剂标示形式和食品添加剂项全部子条件 |
| C.1—C.2 | 长方体最大侧面高×宽；圆柱高×周长×40%；其他形状最大平面/近似平面，无明确平面才用平铺总面积40%；扣除封边及不能印字部分，瓶罐排除规定部位；尺寸缺失则不判面积豁免 |
| D.1—D.5 | 提示形式、直接添加与可能带入的区别；深加工配料清单和单一配料/食用酒精/蒸馏酒的明确豁免 |


## 汇编扩展检查（按资料和任务范围触发）
逐项使用相同四种状态；精确条款从官方原文核对，导航本身不是法源。

| 模块 | 检查及证据 |
| --- | --- |
| 宣传声称 | 整体画面真实性；绝对化、排名引证、疾病保健暗示、零添加和营养声称；语境、配方、报告及适用标准 |
| 品牌视觉及标志 | 名称Logo、商标、字体图像肖像、产地印象、有机等认证；授权和证书范围 |
| 新旧版切换与印样 | 日期字号区域、委托信息、数字标签、内外包装组合装；实施时间、完整条款和1:1实测 |
| 计量 | 净含量标注与实际装量分别查证，适用计量规则及抽检资料 |
| 过度包装 | 适用标准与修改单、层数、空隙率、成本；缺结构尺寸成本则不出合格结论 |
| 食品接触材料 | 材料、接触条件、供应商符合性声明及检验；不以“食品级”宣传代替证据 |
| 渠道一致及促销 | 已提供电商直播等素材的标签同步、广告识别、价格赠品条件；无渠道资料记录未审范围 |
